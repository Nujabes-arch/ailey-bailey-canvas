# 현재 GPT ↔ 프로젝트 기능 동등성 테스트

## 실행 원칙

a. 현재 GPT와 프로젝트에서 각각 새 채팅을 만든다.
b. Setup, Prompt 순서를 그대로 사용한다.
c. 문장 표현은 달라도 된다. 상태 전이와 필수 동작을 비교한다.
d. Critical 항목은 세 번 반복한다.
e. 결과를 RUN_LOG.csv에 기록한다.
